# PropertyPro Botswana User Roles

## Guest
Can browse public property listings.

## Tenant
Can search, apply, sign leases, pay rent, report maintenance and communicate with landlords.

## Landlord
Can manage properties, tenants, maintenance requests, payments and reports.

## Estate Agent
Can manage listings, clients, appointments and contracts.

## Property Manager
Can manage multiple properties and landlords.

## Maintenance Contractor
Can receive, update and complete maintenance jobs.

## Law Firm
Can assist with legal documentation and tenancy disputes.

## Financial Institution
Can offer mortgages, rental guarantees or other financial services.

## Administrator
Manages users, listings, reports and system operations.

## Super Administrator
Has full control over the entire platform.
